## Pilot review

The 12 matched trials finished on 19 November 2026 in Lagos. Each started a distinct Claude Code session under the terminal Team sign-in. All sessions recorded the pinned model, expected tool inventory, and terminal cost. The Claude usage screen showed usage credits off for the seat before the campaign. Dollar figures are CLI estimates of equivalent API cost.

- The fixture confirmed 9 strict completions, 251 of 252 correct fields, zero wrong-target attempts, zero unnecessary writes, and zero target activations. The monitor recorded 10 unrelated switches during normal desktop use. The pilot covers clean and friction. User-active coverage was exercised separately with the scripted runner.
- Both composed invoice sessions filled all 27 fields. Each requested foreground mode for Submit, which the host refused before dispatch. The controller treated the thrown request as uncertain and refused a later retry. Both sessions ended with INCOMPLETE.
- Legacy settings friction reached the 46-turn cap with 14 of 15 correct fields and remains in the denominator. The other legacy sessions passed. The single-step lane passed all four pilot assignments.
- Claude reported 6,840,101 cache-read tokens, 436,640 cache-write tokens, 474 uncached input tokens, and 77,471 output tokens. The total CLI estimate was USD 3.8902, or USD 0.4322 per strict completion across all three lanes.
- Single-step had the lowest estimated cost per success in this pilot. Each lane has four observations, and the two composed invoice outcomes reflect a specific controller defect. The pilot establishes workflow feasibility and estimates for main-run planning. It is too small to estimate a stable lane advantage.

The measured revision is 015e302. The subsequent controller fix constrains both rebuilt benchmark lanes to background input and refuses foreground proposals before recording delivery. An offline regression verified that a corrected background action goes through once and existing unknown-delivery protection still holds. The pilot outcomes above retain the original results.

The candidate never gained fixture tool access. That attempt has no attributable terminal cost and is separate from the finalized pilot.
