# UseUI brand kit

Background control you can follow.

The mark pairs a pointer with an open window frame. It reflects how the app shows where the agent is working.

## Logo files

| Asset | Use |
| --- | --- |
| [App icon source](app-icon.svg) · [1024 px PNG](app-icon.png) | Finder, Dock, installers, and app listings |
| [Ink mark](mark-ink.svg) | Standalone mark on light backgrounds |
| [Mint mark](mark-mint.svg) | Standalone mark on dark backgrounds |
| [Light-background wordmark](wordmark-light.svg) · [Dark-background wordmark](wordmark-dark.svg) | The full product name in docs, web pages, and launch materials |

Use the app icon from **16 px** and the full wordmark from **200 px wide**. Leave at least a quarter of the mark’s width as clear space on every side. Keep the original proportions when scaling.

The wordmarks use outlined type and transparent backgrounds. The downloadable kit also includes a preview board and smaller PNG exports.

## Color

| Color | Hex | Use |
| --- | --- | --- |
| Ink | `#101C2C` | Dark surfaces and primary text on Paper |
| Mint | `#66E9BC` | Pointer and highlights on Ink |
| Paper | `#F2F7F5` | Light surfaces and primary text on Ink |
| Slate | `#506173` | Secondary text on Paper |

Ink and Paper have a contrast ratio of **15.84:1**, Mint and Ink **11.39:1**, and Slate and Paper **5.88:1**. Use Ink or Slate for text on Paper. Keep Mint on Paper decorative.

## Type

Use **Inter Semibold** for brand headings, the **system sans serif** for documentation body text, and **Menlo** for code and hex values. The native app uses the macOS system font. [Inter source and license](https://github.com/rsms/inter)
